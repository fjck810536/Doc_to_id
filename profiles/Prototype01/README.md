# Prototype01 — Reference Design Profile

這是 Doc_to_id 的第一個 reference profile，源自《共犯者的無終奇語》排版實驗。

它的用途：
- 保存已確認的設計決策；
- 作為通用 engine 的 regression reference；
- 示範如何把「原型書」轉成 Design Profile。

它**不是所有書的預設版型**。

重要歷史校正：
- CJK core 是 **Noto Serif CJK TC / Noto Sans CJK TC**，不是 JP。
- body size 約 9.7 pt；Golden PDF 實際有效 leading 約 **12.2 pt**。
- 早期 TeX 看見的 15.8 不可直接當最終 PDF leading。
- PART 預設 recto；ordinary article 不全數強制 recto。
- blank page 是否保留 folio/header 依 page class。
- footnote number 後使用小間距，不用大 tab。
